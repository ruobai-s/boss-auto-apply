# BOSS 自动投递本地 MVP

## 启动

在当前目录执行：

```powershell
mvn spring-boot:run
```

然后使用电脑访问 `http://localhost:18080`。手机访问时，使用电脑局域网 IP，例如 `http://192.168.1.10:18080`。当前管理端未配置登录鉴权，只应在本机或可信局域网使用，不要暴露到公网。

## 内置浏览器连接器

管理端现在可以启动一个由本地服务管理的独立可见浏览器窗口：

1. 点击页面顶部的“启动独立 Edge”。
2. 在弹出的普通 Edge 窗口中手动登录 BOSS；此阶段系统不会建立 Playwright 连接。
3. 手动进入需要采集的职位列表页，并处理平台要求的安全验证。
4. 回到管理端点击“登录后建立连接”，系统此时才通过本地动态 CDP 执行一次受控检测。
5. 连接成功后点击“从独立 Edge 采集”。
6. 使用结束后点击“停止独立 Edge”，系统会关闭本次受管进程并删除临时会话目录。

默认使用本机安装的 Edge，并创建独立临时用户目录，不复用个人浏览器配置，也不读取或导出登录 Cookie。如果确需使用 Chrome，可将 `src/main/resources/application.yml` 中的 `channel` 改为 `chrome`，并配置对应可执行文件路径。

真正把第三方站点页面放进管理网页的 iframe 容易被站点 CSP 或 `X-Frame-Options` 拒绝，因此当前“内置”指由本地服务启动和管理的独立可见浏览器窗口，不是把 BOSS 页面嵌在管理页 DOM 内。

## 当前能力

- 最多配置五个优先城市。
- 城市投递比例必须合计 100%。
- 每日投递总量上限为 150 个岗位。
- 使用最大余数法生成整数城市额度。
- SQLite 本地持久化策略和职位记录，重启后保留。
- 按 `source + sourceJobId` 对职位去重。
- 保存职位描述、公司简介、发布时间等详情字段。
- 明确外包公司/岗位自动排除，并持久化过滤原因。
- 疑似外包岗位进入 `WAIT_CONFIRM`，需要人工复核。
- 响应式布局适配手机和电脑。
- 启动、停止并探测独立的普通 Edge；只在人工登录完成后通过 CDP 连接 Playwright。
- 在管理端显示当前浏览器页面的临时截图预览，截图不落盘。
- 记录页面关闭、浏览器断开、导航失败和空白页等诊断状态；检测到异常时暂停，不自动刷新或反复重启。
- 从当前 BOSS 列表页只读采集已加载职位。
- 导入标准化职位快照，生成城市主额度和补量候选队列。
- 人工确认候选岗位，并对已确认岗位执行单条投递前置检查。
- 兼容 BOSS 城市字段中的区域后缀（例如“北京·朝阳区”），统一匹配到策略城市。
- 只有候选队列人工确认后的职位才能记录为已投递，记录后会锁定对应队列，避免重复准备。

## 浏览器接口

```http
POST /api/browser/embedded/start
POST /api/browser/embedded/connect
GET  /api/browser/embedded/status
GET  /api/browser/embedded/preview
POST /api/browser/embedded/collect
POST /api/browser/embedded/stop
```

采集接口只读取当前页面、去重和执行外包筛选，不会自动翻页，也不会点击投递。

## 当前限制

- BOSS 页面结构会变化，首次真实采集仍需在用户完成安全验证后校准选择器。
- 若 BOSS 风控主动清空或关闭页面，系统只能给出 `PAGE_UNAVAILABLE` / `SECURITY_CHECK_REQUIRED` 诊断并等待人工处理，不能保证阻止页面关闭，也不会绕过风控。
- 系统不会读取或保存密码、验证码、Cookie。
- 系统不会处理验证码、绕过风控或批量点击投递按钮。
- 单条投递入口只检查浏览器状态并提供职位链接，最终点击必须由用户完成。

## 本次修复（2026-09-07）

- 启动时改为直接打开 BOSS 求职职位页，降低首页安全检查导致空白页的概率。
- 页面导航超时或被 BOSS 中止时不再关闭浏览器窗口，保留窗口供用户手动登录或处理安全验证。
- 重新启动前会清理上一次已断开的浏览器引用，避免多个临时上下文互相影响。

- 单条投递准备时复用已连接 Edge 的当前页面打开职位详情，不由管理端新开标签页；最终投递仍须人工点击。

## 登录静默模式

为减少登录页面频繁跳转和刷新，管理端在独立 Edge 运行期间只进行低频轻量状态检查：

- 状态轮询间隔为 15 秒，只读取浏览器连接和当前地址。
- 登录期间不会自动读取页面正文，也不会自动生成预览截图。
- 页面预览只在点击“刷新页面预览”时读取一次。
- 完成人工登录后，需要点击“登录后建立连接”执行一次登录检测。
- 页面发生主导航后需要重新点击建立连接。
- 系统不会自动刷新登录页、处理验证码或绕过安全验证。

## 普通 Edge + 登录后 CDP（2026-09-08）

- Edge 由 Java `ProcessBuilder` 作为普通独立进程启动，登录期间完全不创建 Playwright 驱动。
- CDP 使用随机端口并仅监听 `127.0.0.1`，不会开放给局域网。
- Edge 启动命令包含兼容层重启抑制参数，运行状态同时参考进程句柄和 CDP 端点，避免实际窗口存在但管理端误报断开。
- 登录检测失败时只断开自动化连接并保留 Edge，方便用户继续人工处理。
- 停止时只关闭带有本次临时会话目录标识的浏览器进程；用户自己的其他 Edge 窗口不受影响。
- 临时会话目录在停止后删除，因此下次启动需要重新登录。

## 登录连接识别修复（2026-09-08）

- 新版 BOSS 页面通过个人入口、头像和用户导航标记确认登录，不再只依赖“我的简历”等正文文字。
- 页面仍显示登录入口、登录弹窗或登录提示时，不会误判为已登录。
- 登录检测失败后的主动 CDP 断开不会再显示为“BOSS 页面已关闭”。
- “登录后建立连接”按钮会显示检测进度，并保留本次成功或失败结果，便于继续处理。
## 登录跳转期间的连接重试

用户完成登录后，BOSS 可能还会进行短暂重定向。点击“登录后建立连接”时，系统会最多进行 3 次只读检测，并在每次检测前重新获取当前活动页面。遇到执行上下文销毁、导航竞争或 Frame 分离时，系统只等待后重试，不会刷新页面、主动导航或点击页面。

如果页面连续 3 次仍未稳定，管理端会显示简短的 `PAGE_UNAVAILABLE` 中文提示，自动化连接会断开，但独立 Edge 窗口会保留。请等待页面停止跳转后再次点击“登录后建立连接”。

2026-09-08 验证结果：28 个 Maven 测试全部通过，JavaScript 语法检查和 Maven 打包通过；未登录接口冒烟返回 `STARTED_NEEDS_LOGIN`，未再暴露 `Execution context was destroyed` 堆栈。

## 登录后连接现场确认（2026-09-08）

- 用户已在新临时 Edge 会话中完成人工登录。
- 主动连接接口成功显示 `CONNECTED`；后续只读状态探测返回 `READY`、`loginValid=true`、`readyForCollection=true`。
- 当前 BOSS 页面为职位列表页，登录导航竞争修复已完成端到端验证，可以进入只读职位采集与选择器校准阶段。

## 职位采集期间的页面导航

职位列表在后台重定向或重新加载时，系统会重新获取当前活动页面并最多执行 3 次只读采集。重试期间不会刷新、翻页、点击职位或执行投递。连续导航时返回脱敏的 `PAGE_UNAVAILABLE` 提示，等待页面稳定后可重新采集；不完整职位不会写入数据库。

2026-09-08 验证结果：新增导航重试成功和连续导航脱敏测试，Maven 测试总数为 30，JavaScript 语法检查及 Maven 打包通过。

## 本地管理端安全启动

系统默认只监听 `127.0.0.1:18080`，不会直接向局域网暴露管理接口。页面截图默认关闭。

本机启动：

```powershell
java -jar target/boss-auto-apply-0.1.0.jar
```

如确需手机通过可信局域网访问，必须同时开启局域网访问并设置强随机管理令牌：

```powershell
$env:SERVER_ADDRESS = "0.0.0.0"
$env:BOSS_ALLOW_LAN = "true"
$env:BOSS_ADMIN_TOKEN = ([guid]::NewGuid().ToString("N") + [guid]::NewGuid().ToString("N"))
Write-Host "本次管理令牌：$env:BOSS_ADMIN_TOKEN"
java -jar target/boss-auto-apply-0.1.0.jar
```

手机第一次访问接口时会要求输入管理令牌；令牌只保存在当前浏览器标签页的 `sessionStorage`，关闭标签页后清除。不要通过聊天、URL、截图或日志传递令牌。

如确需手动页面预览，可额外设置：

```powershell
$env:BOSS_PREVIEW_ENABLED = "true"
```

页面预览可能包含账号和求职隐私，不建议在手机或不可信网络中启用。即使启用上述安全措施，也不能保证第三方页面采集不触发 BOSS 平台风控。
