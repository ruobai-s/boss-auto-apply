# BOSS 本地投递助手 Chrome 扩展

## 当前能力

- 与本机 Spring Boot 管理端进行一次性安全配对。
- 定时上报扩展在线状态。
- 检查是否存在 BOSS 标签页。
- 检查页面连接脚本是否生效。
- 识别登录页、职位列表、职位详情、沟通页和安全验证页。
- 列表页只读采集工作经验、学历、公司规模/行业、福利/职位标签、发布时间、急招和在线状态。
- 用户主动打开单个职位详情后，可再次点击采集补充职位描述和详情字段；不会自动批量打开详情页。
- 不读取、导出或上传 Cookie。
- 候选队列确认后由后台定时轮询投递任务，按任务顺序单条领取、打开职位详情并执行安全点击。
- 不处理验证码，不绕过安全验证；遇到访问限制或无法确认结果时立即停止。

## 安装

1. 启动 `boss-auto-apply` 管理端，确认端口为 `127.0.0.1:18080`。
2. 在 Chrome 地址栏打开 `chrome://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本目录：`chrome-extension/`。
6. 打开本地管理端，在“Chrome 扩展连接中心”生成一次性配对码。
7. 点击扩展图标，输入配对码并完成配对。
8. 打开或刷新 BOSS 页面，回到管理端检查连接状态。
9. 在职位列表点击采集获取卡片字段；如需职位描述，手动打开单个职位详情后再次点击扩展中的“采集当前职位详情”。

## 安全边界

扩展仅连接 `http://127.0.0.1:18080` 和 `https://www.zhipin.com/`。配对令牌保存在当前 Chrome Profile 的扩展本地存储中，后端只保存令牌摘要。
